# Personal Finance Tracker – FinanceFlow

## 1. Introduction of Project

FinanceFlow is a full-stack Personal Finance Tracker web application developed to help users manage their income and expenses digitally.

Users can register, log in, add transactions, monitor their financial balance, and analyze their spending habits through an interactive dashboard.

## 2. Technology Stack and Reasons

| Technology | Purpose |
|---|---|
| React.js | Frontend user interface |
| Tailwind CSS | Responsive UI design |
| Node.js | Backend runtime |
| Express.js | REST API development |
| MongoDB | Database storage |
| Mongoose | Database management |
| JWT | Authentication and authorization |
| Axios | API communication |
| Recharts | Financial data visualization |

## 3. Use Cases

- User registration and login.
- Add income and expense transactions.
- View total income, expenses, and balance.
- Search and filter transactions.
- Delete transactions.
- Analyze expenses using charts.
- Switch between dark and light mode.
- Store financial records in MongoDB.

## 4. Research Part

Traditional financial tracking methods, such as notebooks and spreadsheets, require manual calculations and regular updates.

FinanceFlow provides a digital solution for organized financial management.

The project involved research and implementation of:

- Personal finance management systems.
- JWT-based authentication.
- REST API development.
- MongoDB database integration.
- Financial data visualization.
- Responsive web application design.

## 6. Conclusion

FinanceFlow demonstrates a full-stack personal finance management application using React.js, Node.js, Express.js, and MongoDB.

It provides user authentication, transaction management, database storage, and financial analytics.

Future improvements may include budget planning, downloadable reports, recurring transactions, and cloud deployment.
